# Meu Primeiro Projeto: Kanban com HTML e CSS

Criado com HTML e CSS puros, este quadro Kanban foi desenvolvido com a ajuda da [Rocketseat](https://www.rocketseat.com.br/) durante um desafio #BoraCodar.

---

### Sobre o Projeto

O objetivo era construir uma interface de quadro Kanban simples e funcional, aplicando os conceitos fundamentais do desenvolvimento web front-end. Mesmo sendo um projeto inicial, ele representa a empolgação de ver as primeiras linhas de código se transformarem em algo visual e interativo no navegador.

### Tecnologias Utilizadas

* **HTML5:** Para a estrutura e semântica do conteúdo.
* **CSS3:** Para a estilização, cores, fontes e layout dos elementos.

### O Que Aprendi

Como primeiro contato com a programação, este projeto foi a porta de entrada para conceitos essenciais, como:
* Estruturação de páginas web com tags HTML.
* Uso de seletores CSS para estilizar elementos específicos.
* Noções básicas de layout e posicionamento.
* A satisfação de construir algo do zero e vê-lo funcionar!
